# 어비스봇 · 커뮤니티 통합 정보 카드

이 기능은 기존 클립 채널의 **기존 클립 메시지(1567763296151539875)를 재사용**합니다.
기존 메시지를 Components V2 정보 카드로 교체하고 매시간 같은 메시지만 수정합니다.
새 메시지를 게시하지 않으며 서버 배너 정보 메시지는 변경하지 않습니다.
클립 기능은 계속 비활성화 상태로 유지합니다.

## 구성

- **방송 일정**: 기존 `notice_intelligence.py`가 카페 공지에서 확실한
  날짜와 시간을 검출한 `notice_schedule_state.json`을 표시합니다.
  미확인 일정은 만들어내지 않습니다. X 공지 자동 분석은 이 버전에 포함하지 않습니다.
- **기념일 / 주요 기록**: 확인된 생일 2건과 데뷔일 2건을 기본 표시합니다.
  추가 기록은 `/home/ubuntu/chzzk-bot/community_milestones.json`에 검증 후 등록할 수 있습니다.
- **월간 방송 통계**: 치지직 `openDate`(방송 실제 시작 시각)를 사용하고,
  종료 시각은 마지막 방송 중 확인과 최초 방송 종료 확인의 **관측 구간**으로
  저장합니다. 5분을 넘는 수집 공백은 정확도가 부족하므로 통계에서 제외합니다.
  시작·종료 시간과 오차 범위를 표시하며, 종료 시각을 실제보다 정확하다고
  단정하지 않습니다. 이미 진행 중이던 방송도 시작 시각이 확인되면 반영합니다.

### 기념일 파일 예시

아래 항목은 형식 예시이므로 실제 날짜를 검증해 바꿔서 사용하세요.

```json
{
  "events": [
    {"group": "hanayo", "title": "확인된 기념일 이름", "date": "2026-01-01"},
    {"group": "sakihane", "title": "확인된 기념일 이름", "date": "2026-02-01"}
  ]
}
```

설정은 `COMMUNITY_DASHBOARD_ENABLED=1`,
`COMMUNITY_DASHBOARD_CHANNEL_ID=1567760518977167501`,
`COMMUNITY_DASHBOARD_MESSAGE_ID=1567763296151539875`입니다.
클립 스케줄러 `CHZZK_CLIP_ENABLED=0`이 확인된 경우에만 수정합니다.

이전 대시보드 상태 파일에 다른 메시지 ID가 저장돼 있어도 해당 값을
사용하지 않습니다. **기존 클립 메시지 ID만 수정**하고 신규 게시 요청을
보내지 않습니다. 이 메시지 편집 권한이 없으면 안전하게 실패하며 다른
메시지를 생성하지 않습니다.
